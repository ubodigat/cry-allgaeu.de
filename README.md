# Cry IT Allgäu (Satire-Landingpage)

Eine kleine, animierte Satire-Landingpage rund um die legendäre Namensverwechslungsgefahr:
**Kray IT** ↔ **Cry IT**.

- Partikel-Morph: **KRAY → CRY**
- Animierter Darkmode-Hintergrund (Netzwerk + Sterne)
- Optionales Voice-Over (`voice.mp3`)
- Auto-Redirect (mit Countdown) am Seitenende
- Hosting über **GitHub Pages**

## Live
- cry-allgaeu.de  

## Features
- **Interaktiver Hintergrund:** Netzwerk-Linien reagieren auf Mausbewegung, Sterne glimmen leicht bei Hover.
- **Wort-Morphing:** Nur „KRAY“ wandert zu „CRY“, „IT ALLGÄU“ bleibt statisch.
- **Smooth Scroll:** Scrollverhalten ist bewusst entschleunigt.
- **Redirect-Countdown:** Fließender Countdown + Progress-Ring, optional pausierbar (falls aktiviert).
- **Audio Toggle:** Lautsprecher-Button (falls eingebaut), um Voice-Over zu muten.
